Типы игр: превью, главная, страница типа

Только мобильная версия. Превью типа — схема игры без визуального стиля: одна сетка, одни скругления и толщины для всех типов, вместо текста — плашки-заглушки. Показаны три типа: «Пропуски» и «Картинки» убраны по просьбе пользователя. Список плоский, без категорий.

Стиль превью на экранах:

1. Превью типа: три варианта стиля

Крупно — так превью стоит вверху страницы типа. Ниже — 72, 96 и 120px: так оно выглядит в выборе типа и в списках. Каждый вариант сначала проверялся на самом маленьком размере.

A. Контур

белые фигуры, тёмно-синяя обводка, подложка почти белая

B. Блоки (рекомендую)

белые плашки с мягкой тенью на голубой подложке, один акцент — синий

C. Цвет типа

подложка и акцент — свой цвет бренда у каждого типа, по кругу

Правила, общие для всех вариантов

  1. Холст 160×120 (4:3, как у превью заданий), поля 12, шаг сетки 8. Фигуры: плашка-«карточка» со скруглением 6, строка-заглушка высотой 6–8 со скруглением в половину высоты.
  2. Пять ролей фигур, у каждой свой класс: карточка (p-box), строка текста (p-bar), выделенная карточка (p-accent), связь (p-link), значок (p-glyph). Новый тип рисуется только из них, вариант стиля меняет лишь цвета ролей.
  3. Схема показывает действие игры: в викторине выделен выбранный вариант с галочкой, в сопоставлении — линии связей, в «Да/нет» — кнопки с ✓ и ✗. Тип различается формой, а не только цветом.
  4. Нет текста и Ната — нечего переводить и нечему устаревать.
  5. Превью — декоративное (aria-hidden): название типа всегда стоит рядом текстом.

2. Главная: «Как начать» и новый блок

В шаге 1 «Как начать» новый текст: тип игры и визуальный стиль. Сразу за секцией — «Познакомьтесь с нашими играми»: карточки на всю ширину, как плитки выбора типа. Вся карточка — ссылка на страницу типа. Нажимаемость видна по рамке с тенью и круглой стрелке справа. При наведении меняются рамка, стрелка и подчёркивание названия, при нажатии карточка слегка сжимается, при фокусе с клавиатуры появляется контур.
