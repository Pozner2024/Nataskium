# 0003. Разделы библиотеки: один уровень групп

- **Статус:** Заменено [ADR-0006](0006-library-eight-groups.md)
- **Дата:** 2026-11-15

## Контекст
Библиотеку нужно разбить на разделы так, чтобы учителю было просто выбрать, а посетителю — найти.

## Решение
- **Один уровень** — только группы, без предметов внутри. Учитель выбирает группу в настройках задания.
- Группы — данные в таблице `library_groups` (slug, порядок, названия на ru/en/de/fr), не enum.
  Новая группа добавляется миграцией без правки кода.
- Порядок:

| # | slug | Название |
|---|------|----------|
| 1 | `exact` | Точные науки |
| 2 | `it` | Информатика и технологии |
| 3 | `natural` | Естественные науки |
| 4 | `languages` | Языки и литература |
| 5 | `humanities` | Гуманитарные науки |
| 6 | `arts` | Искусство и творчество |
| 7 | `health` | Спорт и здоровье |
| 8 | `vocational` | Профессиональное обучение |
| 9 | `primary` | Начальная школа |
| 10 | `other` | Разное |

- «Разное» обязательна, последняя и группа по умолчанию. «Начальная школа» — предпоследняя.
- `sort_order` с шагом 10, чтобы вставлять новые группы между соседями.
- Slug `quiz` запрещён: занят адресом карточки `/library/quiz/<номер>-<slug>`.

## Последствия
- Простой выбор для учителя: один список из десяти пунктов.
- Внутри группы нельзя отфильтровать по предмету (например, только химию). Если групп окажется мало,
  уровень предметов добавляется отдельным решением.
- Переводы de/fr предложены без носителя языка — проверить до запуска.

## Отвергнутые варианты
- Плоский список предметов (Математика, Биология…) — пользователь предложил группировать по областям.
- Два уровня «группа → предмет» — пользователь выбрал «только группы».
