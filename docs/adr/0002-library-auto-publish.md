# 0002. Автопубликация заданий в библиотеку

- **Статус:** Принято
- **Дата:** 2026-11-15
- **Заменяет:** [ADR-0001](0001-library-publish-toggle.md)

## Контекст
Библиотека нужна наполненной с первого дня. Wordwall публикует задания без отдельного согласия учителя.

## Решение
- Задание публикуется в общую публичную библиотеку **сразу при создании** (`quizzes.is_public`, по умолчанию `true`).
- Предупреждения в интерфейсе нет.
- Отключить публикацию можно **только на платном тарифе**. Тарифа пока нет — отключить не может никто.
  Маршрут скрытия появится вместе с тарифом, модель данных к этому готова.
- Задания с оценкой публикуются так же, как остальные.
- Публичный ответ библиотеки не содержит правильных ответов, `shareToken`, id задания и данных автора.
- Ссылка для класса `/play/<shareToken>` остаётся случайной и `noindex` и у опубликованных заданий.

## Последствия
- Правильные ответы публично не показываются, но любой учитель получит их, взяв копию («Взять себе»).
  Задание с оценкой (контрольная) открыто для всех — принято осознанно.
- Публичный пользовательский контент, включая картинки, без проверки; среди пользователей дети.
  Модерация — позже: суперадмин с удалением мусора. Заготовка — `quizzes.moderation_hidden_at`.
- Задание видно в библиотеке сразу после первого сохранения, ещё недоработанным.
- До публичного запуска условия использования и политика конфиденциальности должны сообщать о публикации.

## Отвергнутые варианты
- Переключатель, выключенный по умолчанию ([ADR-0001](0001-library-publish-toggle.md)) — библиотека пустая.
- Включённый по умолчанию переключатель, доступный всем — не выбран пользователем.
- Предупреждение в интерфейсе при создании — «в Wordwall не предупреждают».
- Отдельные правила для заданий с оценкой — «не важно».
