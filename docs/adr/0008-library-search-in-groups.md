# 0008. Поиск библиотеки — только внутри разделов

- **Статус:** Принято
- **Дата:** 2026-11-15
- **Уточняет:** [ADR-0007](0007-library-public-page.md)

## Контекст
По ADR-0007 на `/library` были поиск и плитки разделов, а поиск показывал список найденного вместо плиток.

## Решение
- На `/library` поиска нет: только заголовок и плитки восьми разделов.
- Поиск по названию есть только на странице раздела `/library/<slug группы>` и ищет внутри раздела.
- API не меняется: `GET /api/library` по-прежнему принимает `q` без `group`, но интерфейс так не вызывает.

## Последствия
- Страница библиотеки проще: один выбор — раздел.
- Найти задание сразу по всей библиотеке нельзя; чтобы искать, нужно сначала выбрать раздел.

## Отвергнутые варианты
- Общий поиск на `/library` (ADR-0007) — пользователь решил убрать.
