# Архитектурные решения (ADR)

Каждое значимое продуктовое или техническое решение — отдельный файл: что решили, почему и чем за это платим.
Файлы читают люди и Claude, поэтому пишем коротко и по-русски.

## Правила

- Имя файла: `NNNN-короткое-название.md`, номера по порядку, без пропусков.
- Принятый ADR **не переписывается**. Решение изменилось — пишем новый ADR, а у старого меняем только статус
  на «Заменено ADR-NNNN». Опечатки и ссылки править можно.
- Статусы: **Предложено**, **Принято**, **Заменено ADR-NNNN**, **Отменено**.
- Старые решения (авторизация, оценивание, картинки, CORS и др.) пока описаны в `docs/architecture.md`, раздел
  «Ключевые решения». Переносим их сюда постепенно — когда снова касаемся темы.
