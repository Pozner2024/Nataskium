# 0007. Библиотека — публичная страница, без вкладки в кабинете

- **Статус:** Принято
- **Дата:** 2026-11-15

## Контекст
Библиотека была заглушкой во вкладке кабинета учителя, а ссылка «Библиотека» в шапке сайта вела на
несуществующий `/library`. Пользователь хочет обычную страницу, одну для всех.

## Решение
- `/library` — публичная страница, только мобильная вёрстка: поиск и плитки восьми разделов
  ([ADR-0006](0006-library-eight-groups.md)) в сетке 2 × 4. Нат — на четырёх плитках в шахматном порядке,
  неподвижный, оживает при нажатии, без звуков.
- Плитка ведёт на `/library/<slug группы>` со списком заданий раздела. Поиск на `/library` показывает
  список найденного вместо плиток.
- Вкладки «Библиотека» в кабинете учителя нет: в кабинете три вкладки — «Задания», «Создать», «Настройки».
  Путь в библиотеку — ссылка в шапке сайта. Кнопки «Открыть библиотеку» на пустом экране «Мои задания» нет.
- Пока без серверной отрисовки: страница отрисовывается в браузере.

## Последствия
- Поисковики страницу пока не видят. Серверная отрисовка — шаг 10 плана `.claude/plans/library.md`.
- Учитель попадает в библиотеку не из кабинета, а через шапку сайта.

## Отвергнутые варианты
- Вкладка «Библиотека» в кабинете (решение 2026-11-12, четыре вкладки) — пользователь решил убрать.
- Сразу серверная отрисовка — отложена, чтобы быстрее увидеть страницу.
