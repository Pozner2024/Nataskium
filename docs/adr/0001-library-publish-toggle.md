# 0001. Публикация в библиотеку по переключателю

- **Статус:** Заменено [ADR-0002](0002-library-auto-publish.md)
- **Дата:** 2026-11-14

## Контекст
Библиотека заданий публичная, как у Wordwall: у библиотечных заданий свои адреса для поисковиков. Нужно было
решить, какие задания учителя туда попадают.

## Решение
Только те, что учитель опубликовал сам: переключатель «Опубликовать в библиотеке» в настройках задания,
по умолчанию выключен.

## Последствия
- Контрольные с ответами не становятся публичными без ведома учителя.
- Меньше контента без модерации.
- Библиотека наполняется медленно.

## Отвергнутые варианты
- Автопубликация всех заданий — риски публичных ответов, модерации и приватности учителя.
