# 0004. Существующие и удалённые задания в библиотеке

- **Статус:** Принято
- **Дата:** 2026-11-15

## Контекст
С появлением библиотеки нужно было решить, что делать с уже созданными заданиями и что происходит
с опубликованным заданием, когда учитель его удаляет.

## Решение
- Миграция `create_library` публикует **все существующие задания** (`is_public = true`, группа «Разное»).
  В базе были только тестовые данные; лишнее пользователь удалит сама.
- Опубликованное задание — та же запись `quizzes`, а не копия. Удаление задания учителем (`deleted_at`)
  убирает его из библиотеки. Видимость в библиотеке: `is_public`, `deleted_at IS NULL`,
  `moderation_hidden_at IS NULL`.
- Несуществующее, удалённое, скрытое и непубличное задание отвечают одинаковым 404: по ответу не отличить.

## Последствия
- Удалённое задание может ещё некоторое время оставаться в кэшах и выдаче поисковиков; 404 убирает его оттуда.
- Удаление аккаунта учителя удаляет и его опубликованные задания (GDPR).
- Копии, которые другие учителя взяли себе, не затрагиваются: это их собственные задания.

## Отвергнутые варианты
- Не публиковать старые задания — в базе только тестовые данные, смысла нет.
- Страница «задание удалено» с кодом 200 — поисковики держали бы пустую страницу в выдаче.
