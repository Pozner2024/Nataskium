# 0005. Копии «Взять себе» не публикуются

- **Статус:** Принято
- **Дата:** 2026-11-15
- **Реализация:** отложена пользователем 2026-11-15 (готов только `ImageStorage.copy`)

## Контекст
Учитель берёт задание из библиотеки в «Мои задания». По [ADR-0002](0002-library-auto-publish.md) всё
созданное публикуется — копии тоже попали бы в библиотеку.

## Решение
- Копия создаётся с `is_public = false` — системное исключение из автопубликации.
- Картинки копируются отдельными файлами в хранилище (S3 CopyObject), а не делятся с оригиналом.
- Связи копии с оригиналом в базе нет. Копия учитывается в лимите 100 заданий учителя.

## Последствия
- Библиотека не зарастает дублями популярных заданий.
- Удаление оригинала или аккаунта автора не ломает копии: у них свои файлы картинок.
- Больше места в хранилище и запросов к S3 на каждое копирование.

## Отвергнутые варианты
- Публиковать копии — дубли в выдаче.
- Общие картинки у оригинала и копии — нарушают правило «одна картинка — одно место», и удаление
  аккаунта автора удалило бы файлы у тех, кто взял копию.
