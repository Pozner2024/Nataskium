# Обрезка картинок в викторине

Утверждено пользователем 2026-11-21.

## Решения
- Картинка вопроса — 16:9.
- Картинки вариантов ответа — 1:1 (как плитки сейчас).
- Обрезка — в браузере (canvas), без новых библиотек; на сервер уходит обрезанный файл, серверные проверки (сигнатура, sharp, перекодирование в WebP, без метаданных) не меняются.
- «Изменить обрезку» — только пока редактор открыт (исходный файл в памяти). После сохранения — «Заменить картинку». Хранение оригинала/параметров или CORS бакета — не делаем, вернуться, если учителя попросят.
